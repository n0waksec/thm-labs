# Cybersecurity Labs & Pentesting Notes

A personal collection of cybersecurity labs, penetration testing exercises, technical notes, and automation scripts.

This repository documents my hands-on learning journey through intentionally vulnerable machines and security labs. Each write-up focuses on the methodology, tools, findings, evidence, and lessons learned throughout the assessment.

## Objectives

- Develop practical penetration testing and enumeration skills.
- Document repeatable methodologies and troubleshooting steps.
- Improve technical reporting and evidence collection.
- Build reusable Bash and Python tools to streamline lab workflows.
- Maintain a searchable reference for techniques, commands, and lessons learned.

## Methodology

Depending on the lab, each write-up may include:

1. **Reconnaissance** — target discovery and port scanning.
2. **Enumeration** — identification of services, endpoints, virtual hosts, and potential attack surfaces.
3. **Analysis** — investigation and validation of relevant findings.
4. **Exploitation** — documented proof of concept when applicable and within scope.
5. **Privilege Escalation** — investigation of privilege boundaries when applicable.
6. **Evidence & Reporting** — commands, outputs, findings, and conclusions.
7. **Lessons Learned** — key takeaways and possible improvements.

Not every machine requires every phase. Findings are distinguished from hypotheses, and conclusions are based on the available evidence.

## Disclaimer

This repository is intended for educational purposes and authorized security testing only.

All activities are performed within designated lab environments or against systems for which permission has been granted. Techniques and scripts must not be used against unauthorized targets.

This repository is continuously updated as new labs are completed, techniques are explored, and tools are developed.
